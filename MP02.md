# Mini Projeto 02 - Central de Comunicações Alienígenas

### Instruções Gerais:

* O projeto deverá ser realizado em **duplas**.
* É obrigatória a organização e padronização do código. Nomes de variáveis e funções devem ser coerentes com seus propósitos. São permitidas exceções para variáveis de uso comum em programação, como `i`, `j`, `temp`, entre outras.
* As diferentes operações sobre strings devem ser implementadas em **funções separadas**, utilizando **ponteiros para manipular a mensagem**. A função `main` deverá apenas controlar o fluxo do programa, realizar as leituras necessárias e chamar as funções correspondentes.
* Não é permitido utilizar funções prontas da biblioteca `string.h`; as manipulações devem ser implementadas manualmente.
* É garantido que os dados de entrada utilizarão apenas a tabela ASCII padrão (ASCII 128): letras sem acentos (sem `á`, `~`, `ç`, etc.), números e pontuações (`!`, `?`, `-`, `.`, `*`, etc.). A mensagem de entrada terá no máximo **10.000 caracteres** (mais o terminador `\0`).

---

### Ideia Geral do Projeto:

Neste projeto, vocês deverão desenvolver uma **Central de Comunicações Alienígenas**, capaz de modificar uma mensagem através de diferentes operações sobre strings.

O programa receberá inicialmente uma mensagem e permitirá que o usuário aplique sobre ela uma **sequência livre de transformações**.

Cada transformação disponível será representada por um código numérico de operação e deverá ser implementada através de uma função própria:

* `1` - Inverter mensagem
* `2` - Deslocar caracteres (recebe um número inteiro `n` a seguir)
* `3` - Trocar pares e ímpares
* `4` - Inverter maiúsculas/minúsculas
* `5` - Rotacionar mensagem (recebe um número inteiro `n` a seguir)
* `6` - Trocar metades
* `0` - Finalizar protocolo

O usuário poderá escolher qualquer sequência de operações:

```text
1
3
4
0
```

Cada operação deve ser aplicada sobre o **estado atual da mensagem**, ou seja, o resultado de uma operação será utilizado como entrada para a próxima.

Exemplo:

```text
Mensagem original
      ↓
Operação 1
      ↓
Operação 3
      ↓
Operação 4
      ↓
Entrada 0
      ↓
Mensagem final
```

O programa continuará recebendo novas operações até que o usuário informe `0` ou um número que não corresponda a nenhuma operação existente.

Nesse momento, o programa deverá encerrar o protocolo e imprimir a **mensagem final resultante**.

---

### Operações a serem implementadas:

As operações devem ser implementadas em **funções separadas**, recebendo a string através de um **ponteiro**. Os tipos de retorno e os nomes exatos das funções podem ser adaptados, mas as **seis operações abaixo são obrigatórias**.

1. **`inverter(char *s)`**

   * Inverte a ordem de todos os caracteres da string.

   Exemplo:

   ```text
   AB!C DE?F → F?ED C!BA
   ```

2. **`deslocar(char *s, int n)`**

   * Desloca cada letra e número da mensagem `n` posições.
   * O alfabeto e os números devem funcionar de maneira circular. Por exemplo, ao ultrapassar `z`, o deslocamento continua a partir de `a`; ao ultrapassar `9`, continua a partir de `0`.
   * Letras maiúsculas devem continuar maiúsculas e letras minúsculas devem continuar minúsculas.
   * Caracteres que não sejam letras ou números não devem ser alterados.

   Exemplo para `n = 2`:

   ```text
   AdkWa-slZ (mSa) 19.01? → CfmYc-unB (oUc) 31.23?
   ```

3. **`trocarParesImpares(char *s)`**

   * Troca os caracteres de posições vizinhas da string:

     * posição `0` com posição `1`;
     * posição `2` com posição `3`;
     * posição `4` com posição `5`;
     * e assim sucessivamente.
   * Caso a string possua uma quantidade ímpar de caracteres, o último caractere permanece em sua posição.

   Exemplo:

   ```text
   ABCDEF → BADCFE
   ```

4. **`inverterCaixa(char *s)`**

   * Transforma todas as letras maiúsculas em minúsculas e todas as letras minúsculas em maiúsculas.
   * Os demais caracteres permanecem inalterados.

   Exemplo:

   ```text
   Alien 42! → aLIEN 42!
   ```

5. **`rotacionar(char *s, int n)`**

   * Rotaciona todos os caracteres da string `n` posições.
   * Os caracteres que ultrapassarem uma extremidade devem reaparecer na outra extremidade da string.
   * Valores positivos e negativos podem ser utilizados para representar sentidos diferentes de rotação.

   Exemplo de uma rotação de duas posições para a direita:

   ```text
   ABCDEF → EFABCD
   ```

6. **`trocarMetades(char *s)`**

   * Troca a primeira metade da string pela segunda metade.
   * Caso a quantidade de caracteres seja ímpar, o caractere central deve permanecer no centro da mensagem.

   Exemplos:

   ```text
   ABCDEF → DEFABC

   ABCDE → DECAB
   ```

---

### Funções Auxiliares:

Além das seis funções principais, o grupo poderá criar **quantas funções auxiliares julgar necessárias** para organizar o código, evitar repetições e reutilizar operações comuns entre diferentes funções.

**DICA:** se várias operações precisarem saber o tamanho da string, por exemplo, vocês podem criar uma função própria equivalente à `strlen` e reutilizá-la sempre que necessário.

### Protocolo de Execução e Formato de Entrada/Saída:

Para viabilizar a correção automatizada e o uso de casos de teste (via redirecionamento de entrada/saída ou Sharif), o programa **não deve imprimir menus interativos nem mensagens intermediárias** (como `"Digite a opção:"`, cabeçalhos ou menus visuais).

#### Formato de Entrada:
1. **Mensagem inicial:** Lida na primeira linha (até a quebra de linha `\n`, com no máximo 10.000 caracteres).
2. **Sequência de operações:** Números inteiros informando as operações a serem aplicadas sobre a mensagem.
   * Para as operações `2` (deslocar) e `5` (rotacionar), deve ser lido em seguida o valor inteiro `n` correspondente.
   * O usuário poderá aplicar uma mesma operação **quantas vezes desejar** e em qualquer ordem.
   * A leitura encerra quando for fornecido o valor `0` ou qualquer número que não corresponda a uma operação válida.

#### Formato de Saída:
* O programa deve imprimir **exclusivamente a mensagem final resultante** ao término do processamento, acompanhada de uma quebra de linha (`\n`).

#### Exemplo 1:

**Entrada:**
```text
ATAQUE AO AMANHECER
1
4
0
```

**Saída:**
```text
recehnama oa euqata
```

#### Exemplo 2 (com parâmetros):

**Entrada:**
```text
Mensagem Secreta 2026!
2 3
1
0
```

**Saída:**
```text
!9535 dwhufhV phjdvqhP
```
